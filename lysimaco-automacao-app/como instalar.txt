1. Instale Python 3.11 ou 3.12.
2. Copie .env.example para .env.
3. Configure API_BASE_URL, AUTOMATION_MACHINE_TOKENS, AUTOMATION_WORKER_ID e NUMERO_MAQUINA.
4. No backend, configure os mesmos tokens exclusivos por máquina em
   AUTOMATION_MACHINE_TOKENS e execute:
   npm run migrate:automation-api
5. No diretório do aplicativo, execute:
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe main.py

O backend e o aplicativo podem rodar em computadores diferentes. Não configure
credenciais do MySQL no aplicativo. O número da máquina pode ser alterado e
salvo diretamente no painel antes de ligar a automação.
