# Lysimaco Digital em React

Projeto convertido de HTML/CSS/JS para React + Vite, mantendo aparência e funcionalidades principais.

## Rodar

```bash
npm install
npm run dev
```

Depois abra o endereço que aparecer no terminal, normalmente:

```txt
http://localhost:5173
```

## Páginas

- Login
- Painel
- Gerenciar Chamadas
- Relatórios
- Configurações

As navegações usam hash:

```txt
#dashboard
#manager
#reports
#config
```
